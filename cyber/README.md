# HelmCare - Proteção de dados (Cybersecurity)

Módulo de proteção dos dados do entregador: regras de PII no motor de parsing (CPF, CNH, telefone, dados de saúde, localização, senhas), Taint Analysis que bloqueia vazamentos em saídas inseguras, tradução das falhas em alertas claros via LLM e o indicador Risco Cidadão no dashboard.
