# HelmCare - Infraestrutura Linux (Operating Systems)

Scripts em Bash que provisionam automaticamente uma VM Debian para executar o HelmCare: configuram rede, hostname e DNS; instalam as dependências da aplicação (.NET, Python, PostgreSQL e nginx); sobem a API principal e o Serviço de Risco como serviços systemd com reinício automático; monitoram CPU, disco e memória com alertas; e registram logs de auditoria. Um teste de falha demonstra a recuperação automática dos serviços.
